# Patient Management System

Full Stack internship project — built with [NestJS](https://nestjs.com), TypeScript, and PostgreSQL.

## Day 1 — NestJS Hello World

- Initialized the NestJS project structure
- `GET /` returns `Hello World!`
- ER diagram for the Schedula / Patient Management module in [`docs/ER-Diagram.md`](docs/ER-Diagram.md)

## Setup

```bash
npm install
npm run start:dev
```

App runs at `http://localhost:3000`.

## Scripts

| Command | Description |
|---|---|
| `npm run start:dev` | Start with hot-reload |
